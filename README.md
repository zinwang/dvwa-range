# DVWA range
> A quick setup for https://github.com/digininja/DVWA

## Environment Set Up
1. Run `install.sh`
```
./install.sh
```

2. Restart or logout your kali

## Usage

### Delpoy the DVWA range

```
./deploy.sh
```

### Check the status of the DVWA range
```
./check.sh
```

### Setup DVWA

1. Open http://127.0.0.1:10000/dvwa/setup.php

2. Click the `Create / Reset Database` button.

3. Login with `admin/password`.

### Shutdown the DVWA range
```
./down.sh
```
